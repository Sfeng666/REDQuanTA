# Manuscript figures

Sources for figures in Feng and Pool (in preparation), *REDQuanTEA: Replication-Enhanced Detection of Quantitative Traits Evolving Adaptively*. Asset files live with the manuscript at `manuscript_REDQuanTA/tex_docx_conversion/Figures & Tables/` in the development workspace. Scripts below are the copies in this repository.

Combo `QST,ratioVbetweenVtotal` is Q<sub>ST</sub> plus V<sub>GB</sub> / (V<sub>G</sub> + V<sub>E</sub>). The V<sub>E</sub>/V<sub>G</sub> grid is `{0.01, 0.1, 1, 10, 100}`. Floor policy is F3 (ridge, α = 0.1).

## Main figures

| Figure | Asset stem | Generating script | Input / notes |
|--------|------------|-------------------|---------------|
| 1 | `Figure 1 QST workflow_both_modes.png` | schematic (not generated by code) | Both modules |
| 2 | `Figure 2 FPR_dynamic_vs_fixed_fst_predefined_VEVG` | Design Module TPR/FPR matrices; stacked layout from the F3 production run | Combo `QST,ratioVbetweenVtotal`; ABC vs ANOVA; dynamic Q<sub>ST</sub> vs fixed F<sub>ST</sub> |
| 3 | `Figure 3 TPR_plot_combined_ABC_QST_ratioVbetweenVtotal` | `workflow/scripts/plot_tpr_combined_methods.R` | Design Module F3 ABC plus same-draw ANOVA baselines |
| 4 | `Figure 4 power_comparison_combined_per_pop_QST.ratioVbetweenVtotal` | `workflow/scripts/plot_sample_structure_comparison.R` | Sample-structure Design runs at the same combo |

Example commands (after Design Module aggregation):

```bash
Rscript workflow/scripts/plot_tpr_combined_methods.R \
  path/to/design_results \
  path/to/design_results/plots

bash workflow/scripts/run_plot_sample_structure_comparison.sh \
  path/to/sample_struct_results \
  "QST,ratioVbetweenVtotal"
```
